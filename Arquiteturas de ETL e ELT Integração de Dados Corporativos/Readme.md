# Apresentação da disciplina

A disciplina de Arquitetura de ELT e ETL para Integrações Corporativas visa apresentar os conceitos fundamentais das arquiteturas de **ETL** (Extract, Transform, Load) e **ELT** (Extract, Load, Transform), com foco nas integrações corporativas. O conteúdo teórico explora o manejo de **dados estruturados** (com formato padronizado e modelo definido), **semi-estruturados** (organizados por *tags* e flexíveis), e **não estruturados** (sem modelo de dados definido), além de abordar os conceitos de *Traditional Data Warehouse* (DW) sob as abordagens *top-down* de Bill Inmon e *bottom-up* de Ralph Kimball. A ementa também engloba **virtualização** (particionamento de servidores físicos em virtuais) e **conteinerização** (agrupamento de código e dependências para portabilidade e escalabilidade), utilizando o **Docker**. As práticas envolvem processamento de dados com o sistema distribuído **Apache Hadoop** e o sistema unificado de análise em larga escala **Apache Spark**, incluindo ingestão e tratamento de dados com **Dataframe API** e **SparkSQL**, utilizando ferramentas como **Pyspark**, **MinIO** e **Postgres**.

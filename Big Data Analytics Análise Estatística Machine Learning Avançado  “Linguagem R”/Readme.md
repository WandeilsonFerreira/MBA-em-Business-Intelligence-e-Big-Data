# Apresentação da disiciplina

A disciplina "Machine Learning: Tópicos Avançados" tem como objetivo aprofundar o estudo de técnicas avançadas de aprendizado de máquina, capacitando os alunos a aplicá-las em problemas reais. O curso se organiza em três eixos principais: Preparação Avançada de Dados, com revisão, tratamento e seleção de características, incluindo métodos de redução de dimensionalidade como LDA e PCA; Modelagem Preditiva e de Agrupamento, voltada para regressão e clusterização na identificação de padrões; e Regressão em Séries Temporais, abordando modelos como ARIMA e SARIMA para previsão de dados sequenciais.

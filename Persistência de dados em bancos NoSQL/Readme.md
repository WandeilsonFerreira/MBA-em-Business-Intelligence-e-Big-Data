# Apresentação da disiciplina

A disciplina de Persistência de dados em bancos NoSQL aborda a importância dos dados como recurso estratégico das empresas e diferencia bancos de dados Relacionais (SQL) e Não Relacionais (NoSQL), destacando as principais tecnologias empregadas: **MongoDB** e **Firebase/Firestore**; **Redis** no modelo Chave-valorpara análise em tempo real; **HBase**, integrado ao **Hadoop/HDFS**, para o modelo de Colunas voltado a Big Data, logs e séries temporais; e **Neo4J**, com a linguagem **Cypher**, para o modelo de Grafos e consultas complexas de relacionamentos. A abordagem enfatiza a **Persistência Poliglota**, combinando múltiplos bancos para enfrentar desafios de escalabilidade e Big Data, e complementa com o uso do **Power BI** como ferramenta de integração e visualização.

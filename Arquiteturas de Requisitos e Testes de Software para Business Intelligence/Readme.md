# Arquiteturas de Requisitos e Testes de Software para Business Intelligence
# Apresentação da disciplina
 A disciplina ministrada por [MSc. Helton Melo Lima (UFPE)](#) foca na Engenharia de Requisitos (ER) para gerenciar a complexidade do desenvolvimento de software BI. O programa inclui o nivelamento da Engenharia de Requisitos e aborda técnicas de elicitação de requisitos, como o Design Thinking. Ao tratar dos requisitos para sistemas de BI, o conteúdo destaca a necessidade de especificar as fontes de dados, que podem ser estruturadas ou não, mencionando tecnologias de bancos de dados como SQL e NoSQL. Além disso, os requisitos técnicos e de arquitetura para esses sistemas envolvem a especificação de Pacotes de ETL (Extract, Transform, Load), visando garantir que os requisitos funcionais, que incluem requisitos de dados e interação com o ambiente, bem como requisitos de qualidade (desempenho, segurança, confiabilidade), sejam devidamente atendidos.

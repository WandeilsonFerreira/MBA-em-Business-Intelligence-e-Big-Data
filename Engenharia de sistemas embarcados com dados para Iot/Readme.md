# Apresentação da disiciplina

A disciplina de Engenharia de Sistemas Embarcados com Dados para IoT apresenta os fundamentos e práticas para o desenvolvimento de soluções inteligentes que integram hardware, software e conectividade, explorando microcontroladores, sensores e atuadores aplicados em dispositivos embarcados. O curso aborda protocolos de comunicação com e sem fio, coleta e tratamento de dados em tempo real, uso de plataformas como Arduino e Raspberry Pi, além de conceitos de Big Data, computação em nuvem e segurança da informação. O objetivo é capacitar o aluno a projetar sistemas embarcados eficientes e escaláveis, capazes de transformar dados em valor dentro do ecossistema da Internet das Coisas (IoT).

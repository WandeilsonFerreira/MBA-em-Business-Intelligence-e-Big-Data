# Apresentação da disiciplina

A disciplina de Arquitetura de Coleta e Armazenamento de Dados (Hadoop/Spark) apresenta os desafios do Big Data e a necessidade de arquiteturas escaláveis e eficientes, explorando a Arquitetura Central do Apache Hadoop com conceitos como HDFS e Map Reduce. O curso detalha o ecossistema com o Apache Hive, que possibilita análises distribuídas em larga escala via HiveQL e o modelo Schema-on-Read, além do uso de Arquivos Parquet para armazenamento colunar otimizado. Também inclui práticas com Docker Compose para criação de ambientes padronizados e isolados, reforçando a compreensão de soluções modernas para coleta, processamento e persistência de grandes volumes de dados.
